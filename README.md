# Sit Any Block

A cushion-style sitting addon for Minecraft Bedrock 1.21.130 using the Script API. Completely automatic — just hold a stick and right-click any block to sit.

## How to Use
1. Download `Sit_Any_Block_v2.0.0.mcaddon`
2. Open the file — Minecraft imports both packs automatically
3. Enable **both** packs in your world settings
4. Turn on **Holiday Creator Features** and **Beta APIs** experiments
5. Hold a **stick** in your hand
6. **Right-click (or long-press on mobile)** any block you're looking at
7. Your character sits on that block!
8. **Crouch** to stand up

## Features
- **Fully automatic** — no command blocks to set up
- **Works on any block** — sit on grass, stone, wood, anything
- **Script API powered** — smooth, real-time detection
- **Clean and invisible** — no floating objects, no visible entities
- **Hold stick → click → sit** — simple and intuitive

## Requirements
- Minecraft Bedrock Edition 1.21.130+
- **Holiday Creator Features** experiment enabled
- **Beta APIs** experiment enabled

## Troubleshooting
- If the chat message "Sit Any Block loaded!" doesn't appear, make sure Beta APIs experiment is on
- If you can't sit, make sure you're holding a stick and right-clicking (not left-clicking)
