# Get Seated

A cushion-style sitting addon for Minecraft Bedrock 1.21.130. Hold a stick, right-click any block, and sit on it.

## How to Use
1. Import `Get_Seated_v2.0.0.mcaddon`
2. Enable both packs + **Holiday Creator Features** + **Beta APIs** experiments
3. Hold a **stick** in your hand
4. **Right-click** (or long-press on mobile) any block
5. You sit!
6. **Crouch** to stand up

## Features
- Fully automatic — no command blocks
- Works on any block
- Script API powered
- Clean invisible entity
- Auto-despawns when not in use

## Requirements
- Minecraft Bedrock Edition 1.21.130+
- Holiday Creator Features experiment ON
- Beta APIs experiment ON
